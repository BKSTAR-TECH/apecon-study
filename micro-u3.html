3.1 The production function

This unit takes the supply curve you drew in Unit 2 and asks where it came from. The answer is here: a firm’s costs are its production with prices attached, and the reason supply slopes upward is a fact about crowding workers into a kitchen.

The chain the whole unit runs on Production → cost → the firm’s output decision → market supply. Each arrow is a topic. Diminishing marginal returns (3.1) make marginal cost rise (3.2); rising marginal cost is what the firm compares with price (3.5); the part of that curve worth producing on is the firm’s supply curve (3.6); and adding those up across firms is the market supply curve of Unit 2. Nothing in Unit 3 is free-standing, which is why an answer that gets the picture right and the mechanism wrong still loses the mark.

The two runs, and what actually separates them

Production function
The recipe: how much output a given set of inputs will make.In real lifeA pizzeria with one oven and three staff turns out about 40 pizzas an hour. Change either number and the 40 changes - that relationship is the production function.The production function explains the relationship between inputs and outputs, and it exists in both runs. In the short run it answers "what happens to output when I add one more worker to the plant I already have"; in the long run it answers "what happens to output when I change the plant as well". It is a statement about physical quantities - workers in, loaves out - with no prices in it anywhere. Every cost curve in this unit is that physical relationship with a price tag attached to the inputs, which is why a change in production shows up as a change in costs two topics later.
Short run
A stretch of time in which at least one input cannot be changed.In real lifeA restaurant can call in two extra cooks tonight. It cannot install a second kitchen tonight. Tonight is the short run.The period over which at least one input is fixed. It is not a number of weeks - it is defined by what the firm can and cannot change, so the short run is months for a food truck and years for a steel mill. This is the run in which diminishing marginal returns operate, because the whole idea of crowding more of one input onto a fixed one requires something to be fixed. Note what the definition does not say: it does not say output is fixed, and it does not say the firm is stuck. It says one input is.
On the exam

Which of the following is the best example of a fixed input for a bakery in the short run?

  1. AThe flour used to make each loaf
  2. BThe hours worked by the counter staff
  3. CThe ovens installed in the shop
  4. DThe electricity used to run the mixers
Answer

C. A fixed input is the one the firm cannot vary over the period in question. Flour, staff hours and electricity all move up and down with this week’s output; the ovens are what the bakery has until it rebuilds. Everything that scales with the number of loaves is a variable input.

Long run
A stretch of time long enough to change every input, including the plant.In real lifeGiven eighteen months, the same restaurant can take the lease next door, knock through and put in a second kitchen. Nothing about its scale is fixed any more.The period over which the firm can adjust every input - staff, materials, machines, buildings, the size of the firm itself. Two consequences carry the rest of the unit. Cost: all costs become variable, so there is no such thing as a long-run fixed cost and no long-run shut-down decision. Structure: this is the run in which firms enter and leave an industry, because being in an industry at all is a choice about a fixed factor. The long run is a set of options, not a date on a calendar.
Fixed input
An input whose quantity does not change when output changes.In real lifeThe delivery van a florist already owns. Twenty orders or two hundred, it is still one van until she buys another.An input the firm cannot vary within the period being described - land, a building, heavy machinery, a licence. It is the existence of a fixed input that makes a period "short run", and it is the fixed input that later shows up as total fixed cost. The exam’s standard set-up is "labor is the only variable input and capital is fixed", which is the whole short-run model in one clause.
Variable input
An input the firm can add or drop as output changes.In real lifeShifts on the rota. A cafe that gets busy schedules more hours this week and fewer next, without buying anything.An input whose quantity moves with output: hours of labour, raw materials, packaging, power. In the short run these are the only things the firm can change, so every short-run change in output comes from changing a variable input - and that is exactly why short-run output eventually runs into diminishing returns. In the long run the distinction disappears, because everything is variable.

The line that separates themNot a length of time - whether anything is fixed. Eighteen months is the long run for a food van and the short run for a power station, and a stem never gives you a number of months: it tells you what the firm can and cannot change, and that is the answer. Everything else follows. Fixed input, therefore fixed cost, therefore something to crowd, therefore diminishing returns, therefore a shut-down decision. Remove the fixed input and all four go with it.

Three ways to count output

One schedule — workers in, output out — read three ways. The definitions are easy and the exam does not ask for them; it asks which one peaks first.

Total product
All the output produced by all the workers, added up.also called total physical product (TPP), total output or QOlder papers and many textbooks write “physical” to stress that it is a count of units and not a sum of money.In real lifeFive people picking apples fill 62 crates between them in a day. 62 crates is total product.The whole quantity of output produced with a given quantity of the variable input. Read a total product curve for its shape, not its height: it rises steeply while each extra worker is adding more than the last, then more gently once diminishing returns set in, and it reaches its maximum where marginal product hits zero. Past that point an extra worker actually reduces output and total product falls. The examined error is putting the peak of total product where marginal product peaks - marginal product peaks much earlier, at the point where total product is steepest.
Marginal product
What ONE more worker adds to output.also called marginal physical product (MPP) or marginal product of labor (MPL)The exam uses all three. MPL just names the input being varied; on this unit that input is almost always labour.In real lifeThe apple orchard hires a sixth picker and the day’s haul goes from 62 crates to 71. That sixth picker’s marginal product is 9 crates.The change in total product from adding one more unit of the variable input: change in output divided by change in input. It is the single most useful number in the unit, because marginal product is what marginal cost is made of - when an extra worker adds fewer units, each unit costs more in wages, so falling marginal product and rising marginal cost are the same event seen from two sides. Marginal product can be positive and falling (normal, and still adding output), or negative (the extra worker gets in the way and total product falls).

Average product
Output per worker: total output divided by the number of workers.In real life62 crates picked by 5 people is 12.4 crates per person - the orchard’s average product that day.Total product divided by the quantity of the variable input, also called output per worker or productivity. It relates to marginal product exactly the way any average relates to its marginal: while the next worker is above the average, the average is pulled up; while the next worker is below it, the average is dragged down. So marginal product cuts average product at the maximum of average product, from above - the same arithmetic that makes marginal cost cut average total cost at its minimum, one topic later.
Diminishing marginal returns
Each extra worker adds less than the one before, once the good spots are taken.also called the law of diminishing returns, diminishing marginal product or diminishing returns to the variable inputDo NOT read it as diminishing returns to SCALE, which is a long-run idea with every input moving. The shared word is the trap this unit is built around.In real lifeA food truck with one serving window. The second worker doubles the queue handled; the fifth is squeezing past the others to reach the fryer and barely adds anything.Diminishing marginal returns occur as a firm employs more of one input, holding other inputs constant, to produce output in the short run. Three things about that sentence are examined separately. One input varies: this is not about the firm getting bigger, it is about crowding more of one thing onto a fixed amount of everything else. The short run: without a fixed input there is nothing to crowd, so the idea has no long-run counterpart. And where it begins: at the output where marginal product reaches its maximum and starts to fall - not where marginal product turns negative, which is much later and is where total product starts falling. Output is still rising throughout; only the additions are shrinking.

The line that separates themThey are one schedule read three ways, and the exam tests the timing, not the definitions. Marginal product peaks first, average product peaks second and exactly where marginal cuts it, and total product peaks last, where marginal reaches zero. The reliable error is putting total product’s peak where marginal product peaks: at that output total product is only at its steepest, and it goes on rising for a long time afterwards.
Trap — where diminishing returns begin Diminishing marginal returns begin where marginal product is at its maximum and starts to fall. They do not begin where marginal product turns negative, and they do not begin where total product peaks — those two are the same, much later point. At the moment diminishing returns set in, output is still rising, the firm is still hiring, and nothing has gone wrong. Only the size of each new contribution has started to shrink.

3.2 Short-run production costs

Every cost in this topic is the production function of 3.1 with a price tag on the inputs. Get the vocabulary sorted first, because the exam tests which curve moves far more often than it tests what a curve is.

The three totals

Total fixed cost
What you owe before you make anything, and it never changes.also called fixed cost, overhead or sunk cost in the short run“Overhead” is the business word for it. Careful with “sunk”: a fixed cost is sunk only once it cannot be recovered, and the exam usually says fixed.In real lifeThe rent on a shop unit and the insurance premium. The landlord is owed the same amount in a week with no customers as in a record week.The cost of the fixed inputs. Its defining property is the one the exam tests: total fixed cost remains constant at all output levels, including zero output. Flat. Not falling, not rising, and not zero when the firm produces nothing - which is precisely why a firm that shuts down still makes a loss equal to its fixed cost, and why fixed cost is the number a shut-down decision is measured against. Do not confuse it with average fixed cost, which falls steeply as output rises for the mechanical reason that a constant is being divided by a bigger and bigger number.
Total variable cost
Everything you only owe because you made something.In real lifeThe flour, yeast and shift hours a bakery uses. Bake nothing on Sunday and you buy no flour on Sunday.The cost of the variable inputs, and therefore zero at zero output - the one place total variable cost and total fixed cost behave in exactly opposite ways. It rises with output, and it rises in a particular shape: slowly at first, while marginal product is still increasing, then steeply once diminishing marginal returns take hold. That change of gear is the same event as marginal cost passing its minimum. Total variable cost is also the number the short-run shut-down decision compares total revenue against.
Total cost
Fixed plus variable. Everything the firm owes at that output.In real lifeA month of a print shop: $3,000 of rent and leases whatever happens, plus $7,400 of paper, ink and hours actually used. $10,400 in total.Fixed costs and variable costs determine the total cost: TC = TFC + TVC. Two readings follow from that and both turn up in the multiple choice. On a graph, total cost is the total variable cost curve shifted up by exactly the fixed cost, so the vertical gap between them is the same at every output - which is why average fixed cost falls forever without ever reaching zero. And at zero output, total cost equals total fixed cost, because the firm has bought no inputs but still owes the rent.

The line that separates themWhat happens at zero output. That single reading separates them, and it is what makes fixed cost irrelevant to every short-run decision: a cost you owe whether or not you open cannot help you decide whether to open. It is also the reason a rise in fixed cost changes a firm’s profit without changing its output - marginal cost has not moved, so the profit-maximizing quantity has not moved either.
The reading everything else hangs on At zero output: TVC = 0, and TC = TFC. A firm that produces nothing has bought no materials and paid no shift hours — but it still owes the rent. That number, the fixed cost it owes for producing nothing, is the loss a shut-down firm makes, and it is the benchmark the whole of topic 3.6 measures against.

The four per-unit costs

Average fixed cost
Fixed cost split over the units: it falls, always, forever.In real lifeA band pays $600 to hire a hall. With 60 tickets that is $10 a head; with 300 it is $2 a head. The hall did not get cheaper - it got shared out further.Total fixed cost divided by quantity. It is the only cost curve in the course with no turning point: a constant divided by a rising number falls at every output and approaches zero without reaching it. This is the whole content of the phrase "spreading the fixed costs". It is also the gap between average total cost and average variable cost, which is why those two curves get closer together as output rises and never meet.
Average variable cost
Variable cost per unit. U-shaped, and its minimum is the shut-down price.In real lifeIngredients and kitchen hours per meal served. A nearly empty restaurant wastes prepped food; a rammed one has cooks tripping over each other. Somewhere in between is cheapest per plate.Total variable cost divided by quantity, and the mirror image of average product: where output per worker is at its highest, variable cost per unit is at its lowest. The curve is U-shaped because average product rises and then falls. Its minimum is the single most examined height on the cost diagram, because it is the price below which a firm shuts down: at any lower price, every unit produced fails to cover even its own variable cost.
Average total cost
Total cost per unit. Its minimum is the break-even price.In real lifeA publisher who spends $18,000 on a print run of 3,000 books has an average total cost of $6 a book - the number that decides whether a $6 cover price is worth printing.Total cost divided by quantity, and equal to average fixed cost plus average variable cost. It is U-shaped for two separate reasons pulling in opposite directions: average fixed cost is dragging it down at every output, and average variable cost is pushing it up once diminishing returns bite. At low output the first effect wins and the curve falls; at high output the second wins and it rises. Its minimum is the break-even price, and in a perfectly competitive long run it is the price - the height where economic profit is exactly zero.
On the exam

At its current output a firm has an average total cost of $18 and a marginal cost of $12, and marginal cost is rising. If the firm produces one more unit, which of the following will happen?

  1. AAverage total cost will rise, because marginal cost is rising
  2. BAverage total cost will fall, because marginal cost is below it
  3. CAverage total cost will be unchanged, because the extra unit is marginal
  4. DAverage total cost will fall to $12, the marginal cost of the extra unit
Answer

B. What matters is not whether marginal cost is rising but whether it is above or below the average. $12 is below the $18 average, so adding a unit at $12 pulls the average down - the same arithmetic as adding a low score to a test average. Rising and below are perfectly compatible, and reading "rising" as "pulling the average up" is exactly the mistake option A makes.

Marginal cost
What ONE more unit adds to total cost.In real lifeA print shop’s 501st poster costs $1.40 in paper, ink and press time. That $1.40 is its marginal cost, and it is what decides whether printing it is worth doing.The change in total cost from producing one more unit: change in total cost divided by change in quantity. Fixed cost never appears in it, because fixed cost does not change - so marginal cost can equally be computed from total variable cost, and a rise in rent does not move the marginal cost curve at all. Its shape comes straight from production: production functions with diminishing marginal returns yield an upward-sloping marginal cost curve, because when the next worker adds fewer units, each unit carries more of that worker’s wage. Marginal cost also cuts average variable cost and average total cost at their minimum points, from below, both times - not a drawing convention but arithmetic: an average falls while the next value is under it and rises once it is over it, so it turns exactly where the two are equal.

What moves the cost curves

Specialization and the division of labor
Split the job into parts, let each person do one, and each unit costs less.In real lifeA sandwich shop at lunchtime: one person on bread, one on fillings, one on the till. The same three people serve far more customers than three people each making a whole sandwich.Breaking production into separate tasks and assigning each worker to one. It reduces marginal costs for firms: no time is lost switching between jobs, each worker gets fast at one thing, and tools can be dedicated rather than shared. The effect on the graph is a marginal cost curve that sits lower - a downward shift, not a movement along - and with it lower average variable and average total cost. It is also part of why marginal cost initially falls before diminishing returns turn it upward.
A change in input costs
Inputs get dearer, every cost curve it touches moves up.In real lifeA minimum-wage increase for a car wash, or a jump in the price of coffee beans for a cafe. Nothing about the process changed; every cup now costs more to make.Cost curves can shift in response to changes in input costs and productivity. Which curves move depends on which input: a dearer variable input (wages, materials, power) lifts marginal cost, average variable cost and average total cost together; a dearer fixed input (rent, a licence fee, a tax on capital) lifts average fixed cost and average total cost and leaves marginal cost and average variable cost exactly where they were. That second case is a standing exam favourite, because a firm whose marginal cost has not moved does not change its output in the short run at all.
On the exam

The annual licence fee a profit-maximizing firm must pay to operate is increased. In the short run, which of the following will occur for the firm?

  1. AIts marginal cost curve shifts up and it produces less
  2. BIts average total cost curve shifts up and its output is unchanged
  3. CIts average variable cost curve shifts up and it shuts down
  4. DAll of its cost curves shift up by the amount of the fee
Answer

B. A licence fee is owed whatever the firm produces, so it is a fixed cost. Fixed costs appear in average fixed cost and average total cost and in neither marginal cost nor average variable cost. Since output is chosen where marginal cost meets marginal revenue and marginal cost has not moved, the profit-maximizing quantity is unchanged - the firm simply earns less, or loses more, at the same output.

A change in productivity
Better technology or better-trained workers, and every unit gets cheaper.In real lifeA laundry replaces its machines with ones that run a cycle in half the time. Same staff, same building, twice the loads - and the cost of washing one load falls.Anything that raises output per unit of input - new equipment, training, a better process - shifts the cost curves down. The mechanism runs through the production function: more output from the same inputs is a higher marginal product, and a higher marginal product is a lower marginal cost. This is the one determinant that essentially never runs the other way, because a technique, once known, is rarely forgotten. Note the direction trap: a rise in productivity lowers costs, while a rise in input costs raises them, and both are described in stems with the word "increase".

Students reliably answer “the firm produces less” because costs went up, and that answer is wrong for every fixed cost and right for every variable one.

3.3 Long-run production costs

The long run is not a longer short run. It is a different question: not “how much should I make in this plant” but “which plant should I have” — and once nothing is fixed, half of topic 3.2 stops applying.

The long run in costs
Given enough time, nothing is fixed - so nothing is a fixed cost.In real lifeA gym on a five-year lease is stuck with the rent this year. When the lease ends it can renew, take a bigger site, or walk away entirely. At that moment the rent stops being fixed.In the long run, firms can adjust all their inputs, and as a result all costs become variable. Three consequences, all examined. There is no long-run fixed cost, so no long-run average fixed cost curve and nothing for the shut-down rule to bite on. The firm chooses its scale - which plant size to operate - rather than being stuck with one. And leaving the industry becomes possible, which is what makes entry and exit a long-run story rather than something a firm does overnight.
Long-run average total cost (LRATC)
The cheapest per-unit cost of each output, once you can build any plant you like.also called long-run average cost (LRAC), the planning curve or the envelope curveLRAC and LRATC are the same curve; papers use both within a few years of each other.In real lifeA brewery choosing between a 40-cask kettle and a 400-cask kettle. For a small output the little one is cheaper per cask; for a big output the big one is. LRATC is the lower of the two, at every output.The lowest average total cost achievable at each level of output when every input can be varied. It is the envelope of the short-run average total cost curves: each short-run curve belongs to one plant size, the firm may pick any of them in the long run, so the long-run curve is the lower boundary of all of them and touches each at exactly one output. The long-run average total cost is characterized by economies of scale, diseconomies of scale, or constant returns to scale (efficient scale) - falling, rising and flat, in that order.
Returns to scale
What happens to output when you scale EVERY input up together.also called increasing returns to scale, decreasing returns to scale or constant returns to scaleA stem naming any one of the three is asking the same proportional question: scale every input, then compare the change in output.In real lifeA courier firm doubles its vans, drivers and depots all at once. Does the number of parcels delivered more than double, exactly double, or less than double? That is its returns to scale.The relationship between inputs and outputs in the long run is described by the scale of production - increasing, decreasing, or constant returns to scale. The test is a proportional one and the stem always supplies both percentages: increase every input by the same proportion, then compare the proportional change in output. Inputs up 50% and output up 100% is increasing returns; up 50% and up 50% is constant; up 50% and up 25% is decreasing. Because every input moves together, no input is fixed and nothing is being crowded - which is exactly what separates this from diminishing marginal returns.
On the exam

A firm increases its labor, capital and land all by 20 percent, and finds that its output increases by 12 percent. The firm is experiencing

  1. Adiminishing marginal returns
  2. Bincreasing returns to scale
  3. Cdecreasing returns to scale
  4. Dconstant returns to scale
Answer

C. Output rose by less than inputs did, in proportion, so the firm has decreasing returns to scale - and on the graph it is on the rising stretch of long-run average total cost. Option A is the trap, and it is wrong for a structural reason rather than a numerical one: diminishing marginal returns require an input to be HELD FIXED, and here every input moved together.

What disappears in the long run No fixed input → no fixed cost → no crowding → no shut-down decision. Every one of those follows from the one before. There is no long-run average fixed cost curve because there is no long-run fixed cost; there are no long-run diminishing marginal returns because there is no fixed input to crowd anything onto; and there is no long-run shut-down rule because a firm that wants out can simply leave.

The three stretches of LRATC

Economies of scale
Getting bigger makes each unit cheaper. The falling part of LRATC.In real lifeA supermarket chain buying rice by the shipping container pays less per kilo than a corner shop buying it by the pallet - and spreads one head office over 900 stores.The stretch over which long-run average total cost falls as output rises. The causes are worth knowing by name, because stems describe them rather than name them: bulk buying, specialisation of labour and management, and spreading large indivisible costs - a factory, a research programme, a brand - over more units. Watch the wording: economies of scale is a claim about average cost per unit falling, not about total cost falling. Total cost always rises with output. A firm with economies of scale over the whole range of market demand is a natural monopoly, which is where Unit 4 picks this up.
Constant returns to scale
Bigger is neither cheaper nor dearer per unit. The flat bottom of LRATC.In real lifeA chain of identical coffee kiosks. The tenth kiosk costs about what the ninth did to run and sells about the same amount - so cost per cup stops changing.The stretch over which long-run average total cost is flat: output and every input move in the same proportion. The CED attaches the phrase efficient scale to this stretch, and that link is load-bearing for topic 3.7 - a long-run competitive firm produces at efficient scale, which is this flat floor, at minimum long-run average total cost. Note that a curve with a single lowest point has an efficient scale too; the flat stretch just makes it a range rather than one output.
Diseconomies of scale
Too big to run well: each unit costs more. The rising part of LRATC.In real lifeA company that grows from 200 to 20,000 staff and discovers that a decision now needs four meetings and six sign-offs. Nobody got worse at their job; coordinating them got expensive.The stretch over which long-run average total cost rises as output rises, because the firm has grown beyond the size it can coordinate: management layers, slower decisions, communication costs, weaker accountability. The examined error is explaining this with diminishing marginal returns. It cannot be that. In the long run nothing is fixed, so there is no fixed input to crowd, and the rising stretch has to be caused by something else. Say "coordination", not "the fixed factor" - the distinction is worth a mark on its own.
Minimum efficient scale
The smallest output at which a firm gets costs all the way down.also called MES or the smallest efficient plant sizeIn real lifeMaking semiconductors needs a fabrication plant costing billions, which only pays off at enormous volume - which is why there are a handful of chip makers and not a thousand.The lowest output at which long-run average total cost reaches its minimum - where the falling stretch ends. A firm producing below it is at a genuine and permanent cost disadvantage, not a temporary one. Compared with the size of the market, the minimum efficient scale plays a role in determining the concentration of firms in a market and the market structure: if it is tiny relative to demand, hundreds of firms can each reach it and the market looks competitive; if it is a large fraction of demand, only a few firms fit, and if it exceeds total demand, one firm is cheapest and you have a natural monopoly. This is the bridge from Unit 3’s cost curves to Unit 4’s market structures.

3.4 Types of profit

Two people can look at the same business and disagree about whether it is making money, and both be right. The exam asks which of them a firm listens to, and the answer is always the economist.

Explicit cost
Money that actually leaves the firm.In real lifeWages paid, rent transferred, the invoice from the flour supplier. Every one of them is a payment somebody received.An out-of-pocket payment to someone outside the firm for an input. These are the costs an accountant records, because they have a receipt attached. Every explicit cost is also an opportunity cost - the money could have bought something else - so explicit costs are a subset of economic costs, never a rival system.
Implicit cost
What the owner gives up by using her own resources here.also called opportunity cost of owner-supplied resources, imputed cost or non-monetary costEvery one of these names the same thing: something the owner gave up that nobody invoiced.In real lifeA woman who leaves a $70,000 job to run her own studio, in a building she owns and could rent out for $18,000. Nobody sends her a bill for $88,000, and it is gone all the same.The value of the owner’s own resources used in the business, measured by the next best use they had. Accounting profit fails to account for implicit costs - the CED’s own three examples are the cost of financial capital, compensation for risk, and an entrepreneur’s time - and if all of those are fully compensated the result is normal profit. The test for whether a cost is implicit is simple: was there a payment? Forgone salary, forgone rent on premises you own and forgone interest on money you put in are all implicit; a salary you pay someone else is not.
Accounting profit
Revenue minus the bills you actually paid.In real lifeThe number at the bottom of a small business’s tax return: takings less wages, rent, stock and utilities.Total revenue minus explicit costs. It is the number in the accounts and on the tax return, and it is almost always larger than economic profit, because it leaves out everything the owner gave up that nobody invoiced. A firm can therefore show a healthy accounting profit and still be a poor use of the owner’s time and money - which is not an accounting error, it is a different question being answered.
Economic profit
Revenue minus EVERY cost, the invisible ones included.also called supernormal profit, abnormal profit, above-normal profit or pure profitBritish-influenced material says “supernormal”. It means economic profit greater than zero, not a different quantity.In real lifeThe studio owner takes $95,000 out of the business after paying her bills - but gave up $88,000 in salary and rent to be there. Her economic profit is $7,000: worth doing, but only just.Total revenue minus explicit costs minus implicit costs, or equivalently accounting profit minus implicit costs. Firms respond to economic profit (loss) rather than accounting profit, and that sentence is the engine of the whole unit: it is economic profit that pulls new firms into an industry and economic loss that drives them out, because those are the numbers that tell an owner whether this is the best use of what she has. A negative economic profit with a positive accounting profit is the standard stem, and it means: the business makes money, and the owner would make more elsewhere.
On the exam

Nadia leaves a job paying $60,000 a year to open a shop. She withdraws $40,000 from savings that had been earning 5 percent interest, and rents premises for $24,000 a year. The shop takes $150,000 in revenue and pays $70,000 in wages, stock and utilities on top of the rent. What is Nadia’s economic profit?

  1. A$56,000
  2. B$24,000
  3. C$18,000
  4. D-$6,000
Answer

D. Explicit costs are $24,000 rent plus $70,000 of other bills = $94,000, so accounting profit is $150,000 - $94,000 = $56,000. Implicit costs are the $60,000 salary forgone and the $2,000 of interest forgone = $62,000. Economic profit is $56,000 - $62,000 = -$6,000. The shop is profitable in the accounts and Nadia is worse off for running it, which is exactly the distinction the question is built on.

Normal profit
Exactly enough to keep you here, and not a penny more. Zero economic profit.also called zero economic profit or breaking even in the economic senseThese are the same state described twice, and the second phrasing is the one that stops students reading it as “earning nothing”.In real lifeA driver who nets $52,000 a year and could earn $52,000 doing anything else she is qualified for. She is fully paid for her time - and indifferent about staying.The level of return at which economic profit is exactly zero: every implicit cost, including the owner’s time and the risk she carries, has been fully compensated. It is a cost, not a windfall - the minimum payment needed to keep the resources in this use rather than their next best one. This is why "firms earn zero economic profit in the long run" does not mean firms earn nothing. It means they earn exactly what they could have earned elsewhere, which is the condition under which nobody has any reason to enter or leave.

3.5 Profit maximization

One rule, true of every firm in every market structure, and it is worth being exact about what it does and does not decide.

Total revenue
Price times quantity. All the money coming in.In real lifeA market stall sells 240 punnets at $3.50 and takes $840 that morning.Price multiplied by quantity sold, TR = P x Q. For a price taker it is a straight line through the origin when drawn against output, because every unit sells for the same price no matter how many are sold. Revenue is not profit and the exam checks that you know it: a firm with rising total revenue can be making a growing loss, because nothing in total revenue says anything about cost.
Marginal revenue
What ONE more unit sold adds to revenue.In real lifeA wheat farmer sells another tonne at the going price of $260 and takes $260 more. Her selling it does not move the price.The change in total revenue from selling one more unit: change in total revenue divided by change in quantity. For a firm in perfect competition this is simply the price, because the firm can sell as much as it likes without moving the market - which is why the firm’s demand curve, its marginal revenue curve and the market price are one horizontal line, written d = MR = P. That equality is what makes the perfectly competitive firm a special case; for every other market structure marginal revenue is below price, and Unit 4 opens on exactly that difference.
The profit-maximizing rule
Keep producing while the next unit adds more than it costs. Stop where MR = MC.also called MR = MC, the marginal decision rule or the equimarginal rule for outputIn real lifeA bakery decides whether to bake one more tray. If the tray sells for more than the flour, power and hour it takes, bake it. Repeat until the next tray no longer does.Firms are assumed to produce output to maximize their profits by comparing marginal revenue and marginal cost, and producing where the two are equal. The logic is one sentence: while MR > MC the next unit adds more to revenue than to cost, so making it increases profit; while MR < MC the last unit was a mistake and cutting back increases profit; only where they are equal is there nothing left to gain either way. This is true of every profit-maximizing firm in every market structure, which is exactly why it cannot on its own tell you anything about perfect competition. And it does not decide whether to produce at all - that is the shut-down test in topic 3.6.
On the exam

A perfectly competitive firm is currently producing 400 units. At that quantity its marginal revenue is $30 and its marginal cost is $22 and rising. To maximize profit the firm should

  1. Aproduce fewer units, because marginal cost is rising
  2. Bproduce more units, until marginal cost has risen to $30
  3. Ckeep producing 400 units, because it is already profitable
  4. Dshut down, because marginal cost is below marginal revenue
Answer

B. Each of the next few units brings in $30 and costs less than $30 to make, so every one of them adds to profit. The firm should expand until rising marginal cost has climbed to meet the $30 price. "Marginal cost is rising" is not a reason to stop - it is what guarantees the rule has a stopping point at all.

The rule, and the reasoning behind it Produce where MR = MC, with marginal cost rising.
  • While MR > MC, the next unit brings in more than it costs. Make it. Profit rises.
  • While MR < MC, the last unit cost more than it brought in. Cut back. Profit rises.
  • Where MR = MC, there is nothing left to gain in either direction. Stop.
Trap — MR = MC is not a claim about perfect competition Every profit-maximizing firm produces where marginal revenue equals marginal cost, monopolies included. What is special about a price taker is a different equation: for it, and only for it, marginal revenue equals the price, so MR = MC is also P = MC. Writing “MC = MR” on a perfect-competition question earns nothing on its own, because it is equally true of the market structure in Unit 4. Write P = MR = MC and you have said something only a competitive firm can say.

3.6 Firms’ short-run and long-run decisions

Two decisions, two clocks, two different costs. Collapsing them into one “when should a firm quit” rule is the most expensive single error in this unit.

Tonight: produce, or produce nothing

The shut-down rule
Produce nothing if the price cannot even cover variable cost.also called the shut-down point, the shut-down price or the operating decisionIn real lifeA seaside cafe in February. Opening means paying staff and buying stock for a handful of customers; the rent is owed either way. Cheaper to stay shut until Easter.In the short run, firms decide to operate - produce positive output - or shut down - produce zero output - by comparing total revenue to total variable cost, or equivalently price to average variable cost. Shut down when P < AVC at the best available output; produce when P > AVC. The reason fixed cost is absent from the test is the whole point: fixed cost is owed whether the firm opens or not, so it cannot influence a decision between opening and not opening. A shut-down firm still loses its total fixed cost, and that loss is the benchmark producing has to beat.
On the exam

A profit-maximizing firm in a perfectly competitive market faces a price of $9. At the output where marginal cost equals $9, its average variable cost is $11 and its average total cost is $16. In the short run the firm should

  1. Aproduce that output, because the price is above marginal cost
  2. Bproduce that output, because shutting down still costs it the fixed cost
  3. Cshut down, because the price is below average variable cost
  4. Dshut down, because the price is below average total cost
Answer

C. The short-run test is price against average variable cost, and $9 is below $11: every unit produced fails to cover even its own variable cost, so producing adds to the loss on top of the fixed cost the firm owes anyway. Option D reaches the right verdict by the wrong test - a price below average total cost but above average variable cost means keep producing, which is the more common case and the one D would get wrong.

The shut-down price
Minimum average variable cost - the lowest price worth opening for.In real lifeA hotel that reckons a night’s cleaning, laundry and reception costs $46 a room will take a $50 booking and turn down a $40 one, whatever the mortgage costs.The height of the minimum of the average variable cost curve, which is also where the marginal cost curve cuts it. Below that price there is no output at which revenue covers variable cost, so the firm produces nothing. Exactly at it the firm is indifferent: producing and shutting down both lose precisely the fixed cost. This is why the firm’s short-run supply curve begins here and not at the origin.
The break-even price
Minimum average total cost - the lowest price that leaves zero economic profit.In real lifeA haulier who works out that a delivery costs $118 all-in, once the truck payments are counted, will not sign a long-term contract at $110 - even though $110 more than covers the diesel.The height of the minimum of the average total cost curve, where the marginal cost curve cuts it. At this price the firm exactly breaks even in the economic sense: zero economic profit, normal profit earned, every implicit cost covered. Above it there is economic profit and firms will want to enter; below it there is economic loss and firms will eventually leave. It is the price a perfectly competitive market is pushed to in the long run, which is why this one height links topic 3.2 to topic 3.7.
The firm’s short-run supply curve
The part of the marginal cost curve at or above minimum average variable cost.also called the portion of MC above minimum AVC or the individual supply curveIn real lifeA print shop’s price list for rush jobs traces its own rising cost of squeezing in one more - until the price on offer no longer covers the ink and the overtime, at which point it takes no jobs at all.Because a price taker produces where marginal cost equals price, the marginal cost curve is the answer to "how much will you supply at this price" - but only over the stretch where producing beats producing nothing. Below minimum average variable cost the firm supplies zero, so the supply curve is the portion of marginal cost at and above minimum average variable cost, and nothing below. Adding up these curves across all the firms is where the market supply curve of Unit 2 comes from, which is also why market supply slopes upward: it inherits the slope from diminishing marginal returns.
The shut-down rule Shut down if P < AVC. Produce if P > AVC. Equivalently, in totals: shut down if total revenue is less than total variable cost. Fixed cost appears nowhere in the test, and that is not an oversight — a cost you owe whether or not you open cannot possibly help you decide whether to open.

Barriers to entry or exit
Anything that stops a new firm joining, or an old one leaving.In real lifeA taxi medallion that costs a fortune to buy keeps newcomers out; a twenty-year lease with no break clause keeps a failing shop in.Obstacles that prevent firms responding to profits and losses: licences, patents, huge start-up costs, control of a scarce input, and on the other side long contracts or equipment that cannot be sold. The whole of topic 3.6 is stated for the case where there are no barriers, and the CED says so explicitly - "in the absence of barriers to entry or exit". That assumption is the one Unit 4 removes, and removing it is what allows a monopoly to hold on to economic profit in the long run when a competitive firm cannot.
Entry
New firms join an industry where there is economic profit to be had.In real lifeOne bubble tea shop opens on a street and does well; within a year there are four more on the same street.In the absence of barriers, firms enter a market in which there are profit-making opportunities. The chain is worth memorising as a chain, because the exam asks for the middle of it: economic profit attracts entry, entry increases market supply, the supply curve shifts right, the market price falls, and each existing firm’s horizontal demand line drops with it - until the profit that attracted the entry is gone. Nothing about the individual firm’s cost curves moves during any of this. Note where the movement happens: the market panel shifts, and the firm panel only re-reads its price.
Exit
Firms leave an industry where they anticipate economic losses.In real lifeA stretch of high street where three of the eight clothing shops close over two years, and the survivors start doing better.Firms exit a market when they anticipate economic losses - and note "anticipate": the decision is about the future, which is why a firm can be losing money today and rationally stay. Exit runs the entry chain backwards: firms leave, market supply shifts left, price rises, and the survivors’ losses shrink until the last of them disappears. It is a long-run decision because it means disposing of the fixed factor, which is precisely what a firm cannot do in the short run.

3.7 Perfect competition: the firm in the short run

Perfect competition is the benchmark the rest of the course is measured against, and almost everything in it follows from one sentence: no single firm is big enough to move the price.

Perfect competition
Many small firms, an identical product, and free entry and exit.also called pure competition or a perfectly competitive marketIn real lifeThe market for a standard grade of wheat. No buyer cares whose field it came from, and no single farm is big enough for its harvest to move the price.A market structure defined by four conditions: a large number of buyers and sellers, an identical (standardized) product, freely available information, and free entry and exit. From those follow the two properties the CED states directly - firms face no barriers to entry and have no market power - and everything else in the topic. A perfectly competitive market is efficient, though the two efficiencies arrive on different clocks: allocative efficiency holds at any competitive equilibrium, productive efficiency only once entry and exit have finished their work.
Price taker
The firm reads the price off the market. It cannot set one.also called a firm facing perfectly elastic demand or d = MR = PThe lowercase d is deliberate and the exam prints it: little d is the single firm’s demand curve, big D is the market’s.In real lifeA single dairy farmer takes whatever the milk price is that month. Asking for a cent more sells nothing; there is no reason to ask for less.At a competitive market equilibrium, firms are price takers and select output to maximize profit by producing the level of output where the marginal cost equals marginal revenue (at the price). Two halves. Price taker: in perfectly competitive markets, firms can sell all their outputs at a constant price determined by the market, so the firm’s own demand curve is horizontal at that price - perfectly elastic - even though the market demand curve slopes down as usual. And because every unit fetches the same price, marginal revenue equals the price, so the rule MC = MR is also MC = P here and only here.
Standardized product
Every firm’s output is identical, so buyers have no reason to prefer one seller.In real lifeTwenty kilos of Grade A copper. Nobody checks the smelter’s logo, and no advertising would make one lot worth more.Also called a homogeneous product. It is what makes the firm’s demand curve horizontal: if a buyer can get an identical unit next door at the market price, no seller can charge a cent above it and keep any customers. It also removes any reason to advertise or brand - a fact the exam uses as a distractor, because the absence of advertising is a symptom of the structure rather than one of its defining conditions. Products that are similar but not identical are monopolistic competition, in Unit 4.
Market power
The ability to raise your price and still have customers.In real lifeA stadium with the only food outlet inside charges $8 for a hot dog. A van outside the gates, one of six, cannot.The ability of a seller to influence the price of what it sells. Firms in perfectly competitive markets have no market power, which is a statement about the firm rather than about the market: the market price certainly moves, and it moves because all the firms and buyers together shift supply and demand. What no single firm can do is move it deliberately. This is the property Unit 4 varies one step at a time, and the size of the gap between price and marginal revenue is how much market power a firm has.
Price as a signal
A price tells everyone what everything else costs, without anyone being told.In real lifeWhen a drought pushes coffee prices up, a cafe owner in another country reprints her menu without ever hearing about the drought. The number carried the news.In perfectly competitive markets, prices communicate to consumers and producers the magnitude of others’ marginal costs of production and marginal benefits of consumption, and provide incentives to act on that information - that is, price equals marginal cost in an efficient market. Read the sentence as being about information first and arithmetic second. A buyer who sees a high price has been told, without being told, that the resources needed to make one more unit are wanted badly elsewhere. That is why economists claim so much for a market price: it is a summary of everybody’s costs that nobody had to compile.
The equation that is only true here d = MR = P Because the firm can sell any quantity at the going price, each extra unit brings in exactly that price — so the firm’s demand curve, its marginal revenue curve and the market price are one horizontal line. Combine it with the rule from 3.5 and the competitive firm produces where P = MC. In every other market structure marginal revenue is below price, and that single difference is what Unit 4 is about.

When something happens, ask which panel it happens in: demand rises in the market panel, and the firm panel responds by sliding its own flat demand line up to the new height. A firm-panel figure that shows the firm’s demand curve sloping down is not a perfectly competitive firm.
Trap — two demand curves, two different shapes The market demand curve slopes down, exactly as it did in Unit 2. The firm’s demand curve is horizontal. Both are true at once and they are not in conflict: buyers as a whole do buy less when the price rises, and no individual seller can raise its price without losing every customer to an identical product next door. A figure showing a downward-sloping demand curve in the firm panel is not drawing perfect competition, whatever it says underneath.
Price as information — the claim the CED makes and prose usually drops In a competitive market, prices communicate to everyone the magnitude of other people’s marginal costs and marginal benefits, and give them a reason to act on it. A buyer who sees a high price has been told, without anyone telling her, that the resources needed to make one more unit are badly wanted somewhere else. That is why P = MC is treated as a result and not a coincidence: the number on the tag is a summary of everybody’s costs that nobody had to compile.
Worked example — a price change, panel by panel A perfectly competitive market for a crop is in equilibrium at $8. A health report raises demand permanently.
In the market panel: demand shifts right, and the price rises to, say, $11. Quantity traded rises.
In the firm panel: nothing shifts. The firm’s horizontal d = MR line simply moves up from $8 to $11, because that is the number the market handed it.
The firm’s response: it slides up its own MC curve to the new, larger quantity where MC = $11 — a movement along marginal cost, not a shift of it. Its costs did not change.
The result: price now exceeds ATC at that quantity, so the firm earns economic profit. Which is exactly the signal the next section is about.

3.7 Perfect competition: the long run, and efficiency

The CED says twice that perfect competition is efficient, and it says it two different ways — once flatly, and once conditioned on long-run equilibrium. The two efficiencies are kept on separate clocks, and this section is where that is settled.

Long-run competitive equilibrium
Price has been driven to minimum average total cost and nobody wants to move.In real lifeA settled trade with dozens of small operators, all charging much the same, none of them getting rich and none of them going under. Nothing pulls anyone in or pushes anyone out.In a short-run competitive equilibrium, price can sit above or below its long-run level, producing profits or losses, and those profits and losses motivate entry or exit that moves price and quantity toward the long run. When it arrives, four things are true at once and the exam may ask for any of them: firms produce at efficient scale, price equals marginal cost, price equals minimum average total cost, and firms earn zero economic profit. Because productive efficiency means producing at minimum average total cost, all four are the same picture: the horizontal price line is tangent to the bottom of the average total cost curve, and marginal cost passes through that same point.
On the exam

A perfectly competitive market is in long-run equilibrium. Which of the following must be true of a typical firm in that market?

  1. AIt earns zero accounting profit and zero economic profit
  2. BIts price equals its marginal cost but exceeds its average total cost
  3. CIts price equals both its marginal cost and its minimum average total cost
  4. DIts marginal cost is below its average total cost at the quantity it produces
Answer

C. In long-run equilibrium the price line is tangent to the minimum of average total cost, and marginal cost cuts average total cost at exactly that minimum - so P = MC = minimum ATC, all at once. Option A is the standard trap: zero ECONOMIC profit is normal profit, which is a perfectly healthy accounting profit, because the owner’s implicit costs have been covered.

Zero economic profit in the long run
Entry and exit compete profits away until nobody has a reason to move.In real lifeThe tenth food truck to arrive at a popular lunch spot is the one that makes the pitch not worth the drive for an eleventh.The result, not an assumption. Economic profit attracts entry, entry raises supply, supply lowers price - and the process only stops when the profit that was driving it has gone. Losses do the same in reverse. So zero economic profit is where the mechanism runs out of fuel, and it depends entirely on there being no barriers to entry or exit; take that away, as Unit 4 does, and profit can persist indefinitely. Say it out loud in the form that stops it sounding like poverty: firms earn normal profit, which is exactly what their owners could earn elsewhere.
Allocative efficiency
The right things are being made: the last unit is worth what it cost.In real lifeA bakery makes the number of loaves where the person buying the last one values it at about what the flour, power and time were worth. One more loaf would be worth less than it took to make.At a competitive market equilibrium the price of a product equals both the private marginal benefit received by the last unit consumed and the private marginal cost incurred to produce the last unit, thus achieving allocative efficiency. Two things to hold on to. It is a condition about the last unit, written P = MC or MB = MC, and it is about the mix of what society produces rather than the cost of producing it. And the word private is doing real work: private benefit and private cost coincide with the social ones only when there is no externality, which is the hook Unit 6 hangs its whole argument on.
Productive efficiency
Nothing is wasted: output is made at the lowest possible cost per unit.In real lifeA dairy running its plant at exactly the volume the equipment was built for - no idle capacity, no overtime patching, the cheapest litre it can manage.Producing at minimum average total cost. In a long-run perfectly competitive equilibrium, productive efficiency implies all operating firms produce at efficient scale, price equals marginal cost and minimum average total cost, and firms earn zero economic profit. Unlike allocative efficiency, it does not hold in a short-run competitive equilibrium: a firm making profits is producing past the minimum of average total cost and a firm making losses is producing short of it, and only entry and exit bring the price to the height where the two coincide. A perfectly competitive market in long-run equilibrium is allocatively and productively efficient - which is the strongest claim the CED makes for perfect competition, and it is made only about the long run.

This is why a long-run question can be phrased four completely different ways and have one answer, and why a firm that satisfies one of them in the short run does not satisfy the others.

How the industry gets there

The entry chain, in the order the exam asks for it Economic profit → firms enter → market supply shifts right → price falls → profit goes to zero. And backwards for losses: economic loss → firms exit → market supply shifts left → price rises → loss goes to zero. Note carefully where the movement happens: everything in that chain except the last step is in the market panel. The firm’s own cost curves never move; it only re-reads a price.
Trap — efficiency in the short run is only half true Allocative efficiency (P = MC) holds at any competitive equilibrium, short run or long. Productive efficiency (production at minimum ATC) holds only in the long run: a firm making profits is producing past the minimum of average total cost, and a firm making losses is producing short of it. So “a perfectly competitive market is efficient” and “in long-run equilibrium it is allocatively and productively efficient” are both correct, and a stem that specifies the short run is testing whether you noticed the difference.

Where the long-run price ends up

The long-run industry supply curve
The line joining one long-run equilibrium to the next, as the industry grows.also called the long-run supply curve (LRS) or the long-run market supply curveNot the short-run market supply curve and not any firm’s supply curve. It joins one long-run equilibrium to the next.In real lifeAsk what a kilo of a crop costs once the market has settled at ten thousand tonnes, and again at twenty thousand. Join the two answers and you have the industry’s long-run supply curve.Not a firm’s supply curve and not the short-run market supply curve, but the locus of long-run equilibria: the price the industry settles at once entry or exit has finished, plotted against the quantity it settles at. Its slope is the whole of PRD-3.A.8, and the slope depends on what expansion does to the firms’ own cost curves. Long-run prices depend on the portion of the long-run cost curves on which firms operate, which is why the same demand increase produces three different long-run prices in three different industries.
Constant cost industry
Expansion does not change input prices, so the long-run price returns to exactly where it started.In real lifeAn industry that hires ordinary labour and buys ordinary materials, using such a small share of each that doubling its size does not move either price.An industry in which entry leaves every firm’s cost curves where they were, so the new long-run equilibrium is at the same price as the old one and the long-run industry supply curve is horizontal. This is the case the exam assumes unless it says otherwise, and the phrase "constant cost" in the first line of a free-response question is what licenses the answer "price returns to its original level". Read that phrase as an instruction rather than as scene-setting: without it, "back to P1" is not a safe answer.
Increasing cost industry
Growth bids up an input’s price, so the long-run price ends higher than it started.In real lifeVineyards expanding into a region with only so much south-facing hillside. The extra demand for land raises what every grower pays for it.An industry big enough in some input market that its own expansion raises the price of that input - specialised land, a scarce skill, a limited raw material. Every firm’s cost curves shift up as the industry grows, so entry stops while the price is still above where it began, and the long-run industry supply curve slopes upward. Compared with a constant-cost industry, the same demand increase leaves a higher long-run price and a smaller expansion in quantity.
Decreasing cost industry
Growth makes an input cheaper, so the long-run price ends below where it started.In real lifeAs solar installation grew, panel makers reached their own efficient scale and a trained workforce appeared, and the cost of an installation fell year after year.An industry whose expansion lowers the price of an input, usually because its own suppliers reach a scale they could not before, or because a specialised pool of labour and know-how forms around it. Cost curves shift down as the industry grows, entry continues past the original price, and the long-run industry supply curve slopes downward. It is the rarest of the three cases and the one most often mis-drawn, because a downward-sloping supply curve looks wrong until you remember it is a line joining equilibria and not a supply curve any firm faces.
On the exam

A perfectly competitive, increasing cost industry is in long-run equilibrium when demand for its product rises permanently. In the new long-run equilibrium, compared with the original one, price and quantity will be

  1. Aprice unchanged, quantity higher
  2. Bprice higher, quantity higher
  3. Cprice higher, quantity unchanged
  4. Dprice lower, quantity higher
Answer

B. Demand rises, price spikes in the short run, and the profits pull firms in. But as the industry expands it bids up the price of the input it depends on, so costs rise and entry stops before the price is all the way back down. Quantity is higher than it was and so is price. Option A is the CONSTANT cost answer, and getting it here is the single most common way to lose this mark.

Almost every free-response question in this unit says "constant-cost" and means it: without that phrase, "price returns to its original level" is not a safe answer.
Trap — “constant-cost” in the first line is an instruction Almost every free-response question in this unit opens with the words constant-cost, perfectly competitive market, and students read them as scene-setting. Worked example — a full long-run adjustment, constant cost A constant-cost, perfectly competitive market for a good is in long-run equilibrium at $30. A permanent rise in demand follows.
1. Short run, market: demand shifts right, price rises to $38, quantity traded rises.
2. Short run, firm: the d = MR line moves up to $38. The firm slides up MC to a larger output and now earns economic profit, because $38 is above its ATC there.
3. The signal: that profit is visible to everyone, and there are no barriers to entry.
4. Long run, market: firms enter. Market supply shifts right, and the price falls.
5. Where it stops: at $30 — the original price, because costs did not change. Not before, because profit still remains above it; not after, because losses would push firms back out.
6. The firm at the end: back to its original output, at minimum ATC, earning zero economic profit. The industry is larger; the typical firm is exactly the size it was.

The card to memorize

Formulas

  • Marginal anything: change in total ÷ change in quantity
  • Average anything: total ÷ quantity
  • TC = TFC + TVC, and at zero output TC = TFC
  • ATC = AFC + AVC, so AFC is the gap between them
  • Accounting profit = TR − explicit
  • Economic profit = TR − explicit − implicit
  • Output: MR = MC, with MC rising
  • Price taker: d = MR = P, so P = MC
  • Shut down if P < AVC; leave if P < ATC for good

The traps, in one list

  • Diminishing returns begin where MP peaks, not where it hits zero
  • Diminishing marginal returns is not decreasing returns to scale
  • Diseconomies of scale is coordination, never crowding
  • Total fixed cost is flat; only average fixed cost falls
  • A fixed-cost rise moves ATC and not output
  • MC below an average pulls it down, even while MC is rising
  • Zero economic profit is normal profit, not nothing
  • MR = MC picks the quantity, never whether to produce
  • A loss-making firm should often keep producing
  • Firm demand is flat; market demand still slopes down
  • Allocative efficiency holds in the short run; productive efficiency does not
  • “Price returns to P1” needs the words constant cost
The two heights that answer most of this unit Minimum AVC is the shut-down price. Minimum ATC is the break-even price. Marginal cost passes through both. They cut the price axis into four bands, and almost every short-run firm question is asking which band the price is in: above min ATC is profit and entry; at it is long-run equilibrium; between the two is a loss worth producing through; below min AVC is shut down.
