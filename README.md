# AP Microeconomics — Unit 1 study page

A single self-contained page covering Unit 1, Basic Economic Concepts:
scarcity and opportunity cost, resource allocation and economic systems,
the production possibilities curve, comparative advantage and trade,
cost-benefit analysis, and consumer choice.

**Read it here: https://bkstar-tech.github.io/apecon-study/**

Every graph is generated from a model rather than drawn by hand — curves are
solved, shifts are translations, and equilibria are intersections — so the
figures stay consistent with each other and with what the exam asks for.
Where a figure shows a change, the change animates on screen: navy is what was
already true, orange is what changed.

Built by BKSTAR. The generator lives in a private repository; this repository
holds only the published page.
